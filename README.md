# JB BOOST

JB BOOST is a mobile-first social media growth platform for ordering Facebook, Instagram, TikTok, YouTube, X and Telegram services.

## Core features
- User registration, login and password recovery
- Social media service catalogue
- Wallet/coins system
- Real KoraPay hosted checkout for buying coins
- Server-side KoraPay verification and webhook crediting
- Social order creation and tracking
- Admin service, user, payment and withdrawal management
- Maroon glass mobile-first interface

## Production
Set the required server environment variables before deployment. Never commit live payment secrets.
